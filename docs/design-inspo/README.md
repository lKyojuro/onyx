# Onyx Design & Motion Inspiration

Sammelordner für visuelle Referenzen, UI-Ideen und Mikro-Animationen für das kommende Onyx-Redesign (besonders für den `gpui-kit` + `gpui-fast`-Spike bei 120–144 FPS).

## Stilrichtung (Referenz `01-dot-matrix-thinking-pill.png`)

* **Oberflächen & Tiefe:** Tiefmattes Obsidian/Graphit (`#080808`–`#141414`), subtile Mikro-Punktmatrix im Hintergrund, klare Pill- & Kartenformen ohne billigen Neon-Overkill.
* **Mikro-Animationen (LED-Dot-Matrix):** Präzise 7×7-LED-Punktmatrix-Indikatoren mit warmem Amber-/Akzent-Glow — ideal für Hintergrund-Aktivität in Onyx (z. B. *Ordnergrößen scannen*, *FTS5-Index aktualisieren*, *Kopieren/Verschieben*, *Suche läuft*).
* **Typografie-Shimmer:** Dezenter Lichtlauf über aktive Status-Labels statt unruhiger Standard-Spinner.
* **Charakter:** Taktil, hardware-inspiriert (Richtung Teenage Engineering / Nothing / präzises Profi-Werkzeug), ruhig im Leerlauf, lebendig bei Interaktion.
